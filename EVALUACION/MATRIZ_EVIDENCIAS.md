# Matriz de evidencias y seguimiento

## Enfoque
Evaluación formativa, continua y descriptiva. La matriz permite registrar avances y necesidades de apoyo; no es una escala para comparar participantes.

| Sesiones 12–14 | Objeto y coleccionable | Asocia una interacción con un resultado visible | Lista de chequeo |
| Sesiones 15–17 | Obstáculo y regla | Explica una regla sencilla y reconoce patrones | Guía de observación |
| Sesiones 18–20 | Proyecto integrador | Integra, prueba, mejora y comunica su creación | Lista de chequeo final |

## Lista de chequeo del proyecto final
Marcar: **Logrado**, **En proceso** o **Requiere apoyo**. Añadir observaciones concretas.

- [ ] Presenta una idea o tema para su videojuego.
- [ ] Incluye un punto de inicio reconocible.
- [ ] Construye al menos cinco plataformas u obstáculos.
- [ ] Incluye decoración relacionada con el tema.
- [ ] Tiene una meta visible.
- [ ] Incorpora un objeto especial o coleccionable.
- [ ] Prueba el recorrido con el personaje.
- [ ] Realiza al menos una mejora después de probar.
- [ ] Explica una regla, interacción o instrucción trabajada.
- [ ] Cuenta qué creó y qué le gustaría mejorar.
