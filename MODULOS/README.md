# Módulos y sesiones

Este directorio contiene las 20 guías de sesión. Cada sesión dura 90 minutos como bloque acompañado y debe incluir pausas y actividades variadas.

## Convenciones
- **Identificación:** número, título, módulo, duración y fecha.
- **Misión:** propósito narrativo para motivar, con historia o contexto.
- **Objetivo y competencias:** qué logra el participante y qué habilidades desarrolla.
- **Conocimientos previos y conceptos nuevos:** qué se usa de sesiones anteriores y qué se introduce.
- **Materiales:** recursos que deben estar preparados.
- **Desarrollo paso a paso:** secuencia detallada con tiempos para facilitar la sesión.
- **Demostración guiada, práctica y reto:** acciones concretas con ubicación exacta en Roblox Studio.
- **Exploración, prueba y errores frecuentes:** cómo comprobar el resultado y resolver problemas.
- **Evidencia, criterios y reflexión:** cómo reconocer el avance y conversar sobre el aprendizaje.
- **Ampliación y acompañamiento:** opción opcional y orientaciones para el adulto.

Cada sesión sigue estas convenciones con 20 secciones (ver `RECURSOS/PLANTILLA_SESION.md` y `DOCUMENTACION/DISENO_PEDAGOGICO.md`).

Antes de comenzar, revisar los documentos de seguridad y orientación familiar en `RECURSOS/`.
